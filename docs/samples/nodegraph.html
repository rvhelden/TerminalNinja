Node Graph

Topology graph with force-directed auto-layout and selectable nodes.

Try in Playground

Overview

The NodeGraph control visualizes a topology or network: each GraphNode is drawn as a small labeled box and each GraphEdge as a braille line connecting the boxes it references by Id. Positions are computed automatically with a deterministic force-directed layout (Fruchterman–Reingold) — you supply only nodes and edges, never coordinates, and the same data always renders the same picture. Nodes are set as content; edges via the NodeGraph.GraphEdges property element. 

<NodeGraph Title="Service topology">
    <GraphNode Id="lb" Name="load balancer" />
    <GraphNode Id="web1" Name="web-1" />
    <GraphNode Id="web2" Name="web-2" />
    <GraphNode Id="api" Name="api" />
    <GraphNode Id="db" Name="postgres" />
    <GraphNode Id="cache" Name="redis" />
    <NodeGraph.GraphEdges>
        <GraphEdge From="lb" To="web1" />
        <GraphEdge From="lb" To="web2" />
        <GraphEdge From="web1" To="api" />
        <GraphEdge From="web2" To="api" />
        <GraphEdge From="api" To="db" />
        <GraphEdge From="api" To="cache" />
    </NodeGraph.GraphEdges>
</NodeGraph>

Properties

PropertyTypeDescription
GraphNodesIList<GraphNode>Inline node collection (content property).
GraphEdgesIList<GraphEdge>Inline edge collection, set via the NodeGraph.GraphEdges property element.
GraphNodesSourceIEnumerableOptional bound node collection; overrides GraphNodes when set.
GraphEdgesSourceIEnumerableOptional bound edge collection; overrides GraphEdges when set.
SelectedIndexintIndex of the selected node (-1 = none). Two-way bindable.
SelectedNodeobjectThe selected node, kept in sync with SelectedIndex. Two-way bindable.
LayoutIterationsintForce-simulation budget, clamped to 1–200 (default 60). The layout stops earlier once it converges.
ShowEdgeArrowsboolDraw a direction marker (▶ ◀ ▲ ▼) at each edge’s target end, in the edge’s own color. Default True.
TitlestringOptional heading drawn along the top edge.

GraphNode fields: Id, Name (the box label; also the text content), Value, Color. GraphEdge fields: From, To (matching a node Id — unknown ids are ignored) and Color (defaults to the axis color). GraphNode.Tag carries an arbitrary payload so a selection leads straight back to the domain object. ShowAxes, ShowGrid and ShowLegend have no effect on this chart.

Data Binding

Bind GraphNodesSource and GraphEdgesSource to ObservableCollections on your ViewModel — adding or removing items re-renders and re-layouts automatically. Data classes and ViewModels must be public or internal so the AOT source generator can bind them. 

public sealed class TopologyViewModel : ViewModelBase
{
    public ObservableCollection<GraphNode> Nodes { get; } =
    [
        new GraphNode { Id = "api", Name = "api" },
        new GraphNode { Id = "db", Name = "postgres" },
    ];

    public ObservableCollection<GraphEdge> Edges { get; } =
    [
        new GraphEdge { From = "api", To = "db" },
    ];
}
<NodeGraph GraphNodesSource="{Binding Nodes}"
           GraphEdgesSource="{Binding Edges}" />

Interactivity

The graph is focusable. Give it focus (Tab, or click) and use the arrow keys to move the selection through the nodes in declaration order — Home/End jump to the first and last node — or click any box. The selected box is highlighted (brighter while focused) and SelectedIndex/SelectedNode update two-way, ready to drive a details pane. 

<NodeGraph GraphNodesSource="{Binding Nodes}"
           SelectedNode="{Binding Selected, Mode=TwoWay}" />

Key Concepts

  • Layout is deterministic: positions are seeded on a circle by node index and refined by a force simulation, so identical data renders identically.
  • Edges are drawn with braille sub-cell lines (2×4 dots per cell) and pass beneath the node boxes.
  • Node border colors come from the chart palette, overridable per node with Color; labels are truncated with an ellipsis.
  • Edges reference nodes by string Id; edges with unknown endpoints are silently ignored.
  • Layout is cached and recomputed only when the node/edge set changes; graphs beyond 500 nodes show a "… N more" notice instead of hanging on the O(n²) simulation.
