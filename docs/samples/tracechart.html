Trace Chart

Distributed-trace waterfall of nested spans on a shared time axis.

Try in Playground

Overview

The TraceChart renders a waterfall of TraceSpan rows, modeled on the spans of a distributed trace. Each span is drawn as one row with an indented name and a duration bar positioned on a shared time axis — offset by StartMs and sized by DurationMs. Nested spans supplied via child <TraceSpan> elements are flattened and indented by depth. Bar edges use eighth-blocks for sub-cell precision. Provide spans inline or bind SpansSource. 

<TraceChart Title="GET /api/order/42" LabelWidth="18">
    <TraceSpan Name="http.request" StartMs="0" DurationMs="120">
        <TraceSpan Name="auth" StartMs="2" DurationMs="15" />
        <TraceSpan Name="db.query" StartMs="20" DurationMs="60">
            <TraceSpan Name="connect" StartMs="20" DurationMs="8" />
            <TraceSpan Name="exec" StartMs="30" DurationMs="45" />
        </TraceSpan>
        <TraceSpan Name="serialize" StartMs="85" DurationMs="30" />
    </TraceSpan>
</TraceChart>

Data Binding

Bind a collection of spans from a ViewModel to SpansSource. The chart subscribes to INotifyCollectionChanged, so streaming spans in as a trace completes re-renders the waterfall automatically. Data classes and ViewModels must be public or internal so the AOT source generator can bind them. 

public sealed class TraceViewModel : ViewModelBase
{
    public ObservableCollection<TraceSpan> Spans { get; } =
    [
        new TraceSpan { Name = "http.request", StartMs = 0, DurationMs = 120 },
        new TraceSpan { Name = "auth", StartMs = 2, DurationMs = 15, Depth = 1 },
    ];

    // Spans arriving from a live trace re-render the waterfall automatically.
    public void OnSpanReceived(string name, double start, double duration, int depth) =>
        Spans.Add(new TraceSpan { Name = name, StartMs = start, DurationMs = duration, Depth = depth });
}
<TraceChart SpansSource="{Binding Spans}" LabelWidth="18" />

A bound span list is flattened as-is; set each span's Depth to control indentation, or supply a nested tree via Children and let the chart derive it.

Key Concepts

  • All spans share one time axis; a bar's position encodes StartMs.
  • Nested Children are flattened; depth drives label indentation.
  • Bar right-edges use left-eighth blocks for sub-cell duration precision.
  • Row colors come from the theme palette, overridable via TraceSpan.Color.
  • Bind live traces through SpansSource.
