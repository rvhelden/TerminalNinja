Advanced Controls

TabControl, TreeView, and ListView for complex data display.

Try in Playground

Overview

TabControl extends Selector and displays a strip of tab headers with a content area below. Switching tabs renders different content. Tab headers use box-drawing characters with the selected tab visually connected to the content area.

TreeView extends Control and displays hierarchical data with expand/collapse indicators (▼/▶). Nodes are indented by 2 characters per depth level. Keyboard navigation supports arrow keys for movement and Left/Right for collapse/expand.

ListView extends Selector and adds multi-column layout with headers, separator lines, and column separators. Columns can have fixed widths or star-sizing (fill remaining space). Supports DisplayMemberBinding for extracting cell text from data properties. 

<!-- TabControl with content switching -->
<TabControl>
    <TabItem Header="Tab1">
        <TextBlock Text="Content for Tab 1" />
    </TabItem>
    <TabItem Header="Tab2">
        <TextBlock Text="Content for Tab 2" />
    </TabItem>
</TabControl>

<!-- TreeView with nested items -->
<TreeView>
    <TreeViewItem Header="Root" IsExpanded="True">
        <TreeViewItem Header="Child 1" />
        <TreeViewItem Header="Child 2" />
    </TreeViewItem>
</TreeView>

<!-- ListView with columns -->
<ListView ItemsSource="{Binding Files}">
    <!-- Columns defined programmatically -->
</ListView>

Key Concepts

  • TabControl: Left/Right arrow keys switch tabs; TabItem has Header and Content
  • TreeView: Up/Down move between visible nodes; Left collapses or goes to parent; Right expands or goes to first child; Enter/Space toggles expand
  • ListView: Columns collection with ListViewColumn (Header, Width, DisplayMemberBinding); star-sizing for proportional widths
  • All three support theme-aware colors via implicit styles
  • SelectedItem / SelectedIndex for selection tracking (TabControl, ListView inherit from Selector)
