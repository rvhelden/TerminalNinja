Form Controls

CheckBox, RadioButton, and ComboBox for building interactive forms.

Try in Playground

Overview

CheckBox extends ButtonBase and toggles an IsChecked property. Renders as [x] / [ ] with optional content label.

RadioButton also extends ButtonBase. RadioButtons with the same GroupName under the same parent are mutually exclusive — checking one unchecks the others. Renders as (*) / ( ).

ComboBox extends Selector and shows the selected item in a bordered display with a ↓ indicator. Opens a dropdown popup for item selection. 

<!-- CheckBox -->
<CheckBox Content="Enable notifications" IsChecked="True" />
<CheckBox Content="Dark mode" />

<!-- RadioButton group -->
<RadioButton GroupName="Size" Content="Small" />
<RadioButton GroupName="Size" Content="Medium" IsChecked="True" />
<RadioButton GroupName="Size" Content="Large" />

<!-- ComboBox -->
<ComboBox ItemsSource="{Binding Colors}"
          SelectedItem="{Binding SelectedColor, Mode=TwoWay}" />

Key Concepts

  • CheckBox: IsChecked toggles on Enter/Space/Click; Checked/Unchecked events
  • RadioButton: GroupName for mutual exclusion; does not toggle off (WPF behavior)
  • ComboBox: IsDropDownOpen, MaxDropDownHeight, SelectedItem/SelectedIndex
  • All three support Command binding (inherited from ButtonBase / Selector)
  • Focus/hover visual states with customizable colors
  • Full theme support via implicit styles
