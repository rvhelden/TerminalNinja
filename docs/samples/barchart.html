Bar Chart

Grouped and stacked bars with sub-cell precision, axes, and legend.

Try in Playground

Overview

The BarChart control renders one or more ChartSeries as categorical bars. Series can be laid out grouped (side by side) or stacked, in either vertical or horizontal orientation. Bar lengths use Unicode eighth-blocks for smooth sub-cell resolution, and a "nice-number" value axis, dotted grid, category labels, and a legend are drawn automatically. Provide data inline with <ChartSeries>/<ChartDataPoint> elements, or bind a collection to SeriesSource. 

<BarChart Title="Quarterly revenue" BarMode="Grouped">
    <ChartSeries Name="2024">
        <ChartDataPoint Label="Q1" Value="42" />
        <ChartDataPoint Label="Q2" Value="55" />
        <ChartDataPoint Label="Q3" Value="30" />
        <ChartDataPoint Label="Q4" Value="70" />
    </ChartSeries>
    <ChartSeries Name="2025">
        <ChartDataPoint Label="Q1" Value="35" />
        <ChartDataPoint Label="Q2" Value="60" />
        <ChartDataPoint Label="Q3" Value="48" />
        <ChartDataPoint Label="Q4" Value="90" />
    </ChartSeries>
</BarChart>

<!-- Stacked, horizontal -->
<BarChart BarMode="Stacked" Orientation="Horizontal"> ... </BarChart>

Properties

PropertyTypeDescription
SeriesIList<ChartSeries>Inline series collection (content property).
SeriesSourceIEnumerableBound series collection; overrides Series.
BarModeBarModeGrouped or Stacked.
OrientationOrientationVertical (default) or Horizontal.
ShowValuesboolDraw each bar's numeric value at its tip.
ShowAxes / ShowGrid / ShowLegendboolToggle chart chrome.
SelectedIndex / SelectedItemint / objectTwo-way selection hooks (reserved for interaction).

Key Concepts

  • ChartSeries.Values holds ChartDataPoint items (Label + Value).
  • Bars use eighth-block characters (▁▂▃▄▅▆▇█) for sub-cell precision.
  • The value axis is auto-scaled to "nice" round numbers with a dotted grid.
  • Series colors come from the theme-aware palette, overridable via ChartSeries.Color.
  • Bind live data through SeriesSource with an ObservableCollection.
