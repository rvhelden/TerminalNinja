DataGrid

Read-only multi-column grid with sorting indicators and row selection.

Try in Playground

Overview

DataGrid extends Selector and provides an enhanced tabular data view with sortable column headers and row selection. Columns are defined via DataGridColumn objects specifying Header, Width, DisplayMemberBinding, SortDirection, and IsSortable. When a column is sorted, the header displays a sort indicator: ▲ for ascending and ▼ for descending. Column separators use │, header lines use ─, and crossings use ┼. The selected row is highlighted with configurable colors.

Basic Example

<DataGrid SelectedIndex="0">
  <DataGrid.Columns>
    <DataGridColumn Header="Name" Width="20" />
    <DataGridColumn Header="Age" Width="8" />
    <DataGridColumn Header="Department" Width="18" />
  </DataGrid.Columns>
  <DataGridRow Content="Alice                28      Engineering" />
  <DataGridRow Content="Bob                  34      Marketing" />
  <DataGridRow Content="Charlie              22      Design" />
</DataGrid>

Examples

Sorting Columns

<DataGrid SelectedIndex="0" CanSort="True">
  <DataGrid.Columns>
    <DataGridColumn Header="Name" Width="20"
                    SortDirection="Ascending" />
    <DataGridColumn Header="Score" Width="10"
                    IsSortable="True" />
    <DataGridColumn Header="Date" Width="14"
                    IsSortable="True" />
  </DataGrid.Columns>
  <DataGridRow Content="Alice                95     2026-04-10" />
  <DataGridRow Content="Bob                  87     2026-04-11" />
  <DataGridRow Content="Charlie              92     2026-04-12" />
</DataGrid>

Without Grid Lines

<DataGrid ShowGridLines="False" SelectedIndex="1">
  <DataGrid.Columns>
    <DataGridColumn Header="File" Width="25" />
    <DataGridColumn Header="Status" Width="12" />
    <DataGridColumn Header="Size" Width="10" />
  </DataGrid.Columns>
  <DataGridRow Content="Program.cs               Modified     4.2 KB" />
  <DataGridRow Content="App.xaml                  Unchanged    1.1 KB" />
  <DataGridRow Content="README.md                 New          2.8 KB" />
</DataGrid>

ItemsSource Binding with Columns

<DataGrid ItemsSource="{Binding Employees}" SelectedIndex="0">
  <DataGrid.Columns>
    <DataGridColumn Header="Name" Width="20"
                    DisplayMemberBinding="{Binding Name}" />
    <DataGridColumn Header="Role" Width="15"
                    DisplayMemberBinding="{Binding Role}" />
    <DataGridColumn Header="Salary" Width="12"
                    DisplayMemberBinding="{Binding Salary}" />
  </DataGrid.Columns>
</DataGrid>

Key Concepts

  • DataGrid extends Selector, inheriting SelectedIndex, SelectedItem, and SelectionChanged event.
  • Columns are defined via DataGridColumn objects with Header, Width, optional DisplayMemberBinding, and sort configuration.
  • A Width of 0 uses star sizing, meaning the column fills all remaining horizontal space.
  • Sort indicators ▲ (ascending) and ▼ (descending) are rendered in the header next to the column title when SortDirection is set.
  • Set IsSortable="False" on individual columns or CanSort="False" on the grid to disable sorting.
  • When ShowGridLines is True, columns are separated by │ characters, header lines use ─, and crossings use ┼.
  • Row data can be provided inline with <DataGridRow> elements or generated from ItemsSource with DisplayMemberBinding on each column.
