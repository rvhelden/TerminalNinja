Line Chart

Multi-series line charts drawn with a high-resolution braille canvas.

Try in Playground

Overview

The LineChart control plots one or more ChartSeries as continuous lines. Each series is rendered into a braille canvas (2×4 dots per cell), giving smooth curves at four times the vertical and twice the horizontal resolution of a plain cell. Points are spread evenly along the x axis by index; the y axis auto-scales unless YMin/YMax are set. Provide data inline or bind SeriesSource. 

<LineChart Title="Request latency (ms)" ShowMarkers="True">
    <ChartSeries Name="p50">
        <ChartDataPoint Value="12" />
        <ChartDataPoint Value="18" />
        <ChartDataPoint Value="9" />
        <ChartDataPoint Value="22" />
    </ChartSeries>
    <ChartSeries Name="p99">
        <ChartDataPoint Value="40" />
        <ChartDataPoint Value="55" />
        <ChartDataPoint Value="35" />
        <ChartDataPoint Value="70" />
    </ChartSeries>
</LineChart>

Properties

PropertyTypeDescription
SeriesIList<ChartSeries>Inline series collection (content property).
SeriesSourceIEnumerableBound series collection; overrides Series.
ShowMarkersboolDraw a marker at each data point.
YMin / YMaxdoubleExplicit y-axis bounds; NaN (default) auto-scales.
ShowAxes / ShowGrid / ShowLegendboolToggle chart chrome.

Data Binding

Bind a collection of series from a ViewModel to SeriesSource. The chart subscribes to INotifyCollectionChanged, so adding or removing a series re-renders automatically — ideal for a live dashboard. Data classes and ViewModels must be public or internal so the AOT source generator can bind them. 

public sealed class LatencyViewModel : ViewModelBase
{
    public ObservableCollection<ChartSeries> Metrics { get; } =
    [
        new ChartSeries { Name = "p50",
            Values = { new() { Value = 12 }, new() { Value = 18 }, new() { Value = 9 } } },
        new ChartSeries { Name = "p99",
            Values = { new() { Value = 40 }, new() { Value = 55 }, new() { Value = 35 } } },
    ];

    // Swapping a whole series in re-renders the chart automatically.
    public void ShowP999() => Metrics.Add(new ChartSeries
    {
        Name = "p999",
        Values = { new() { Value = 90 }, new() { Value = 120 }, new() { Value = 80 } }
    });
}
<LineChart SeriesSource="{Binding Metrics}" ShowMarkers="True" />

Note: ChartSeries.Values is a plain list; to push a new point onto a live series, replace the series (or reassign its values) rather than mutating the existing list.

Key Concepts

  • Lines are drawn with a BrailleCanvas for crisp 2×4 sub-cell resolution.
  • Each series gets a distinct palette color, overridable via ChartSeries.Color.
  • The y axis auto-scales to "nice" round numbers; override with YMin/YMax.
  • ShowMarkers="True" highlights individual data points.
  • Bind live data through SeriesSource for streaming updates.
