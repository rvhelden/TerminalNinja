TerminalNinja

WPF-inspired TUI for .NET, built native AOT-first.

Build rich terminal interfaces with a familiar dependency property system, XAML markup, and modern rendering architecture designed for performance and deployment simplicity.

Why TerminalNinja

  • WPF-inspired control hierarchy and dependency property model
  • XAML-first authoring with bindings, templates, and static resources
  • Native AOT-oriented architecture with source generators and registries
  • Efficient terminal rendering focused on low overhead updates

01 - Getting Started

Create your first app in a few minutes.

  1. Create a console app targeting net10.0-windows.
  2. Add a project reference to TerminalNinja.
  3. Define your UI in XAML.
dotnet new console -n NinjaApp
dotnet add NinjaApp/NinjaApp.csproj reference TerminalNinja/TerminalNinja.csproj
dotnet run --project NinjaApp/NinjaApp.csproj
<Window xmlns='http://schemas.terminalninja.dev/xaml'
        Title='Getting Started'
        Width='80' Height='24'>
  <StackPanel Orientation='Vertical'>
    <TextBlock Text='Welcome to TerminalNinja' />
    <Button Text='Run' />
  </StackPanel>
</Window>

02 - WPF Concepts in the Terminal

TerminalNinja keeps WPF mental models so desktop developers can move fast.

Dependency Properties

Control state is DP-backed for metadata, callbacks, styling, and binding support.

XAML-First UI

Describe UI declaratively with the TerminalNinja XML namespace and familiar property syntax.

Binding + DataContext

Use {Binding}, RelativeSource, converters, and view-model patterns.

Resources + Styles

Share values with StaticResource and apply consistent look with Style/Setter.

<Window xmlns='http://schemas.terminalninja.dev/xaml'
        Title='Concept Demo' Width='80' Height='24'>
  <StackPanel Orientation='Vertical'>
    <TextBlock Text='{Binding AppTitle}' />
    <Button Text='Run Command' />
  </StackPanel>
</Window>
